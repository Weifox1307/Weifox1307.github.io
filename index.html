Weirun

Приложение для бегунов. Читает пульс с внешних датчиков по Bluetooth Low Energy, хранит тренировки на устройстве и синхронизирует их с сервером. Есть система достижений и собственные UI-компоненты.

Архитектуру и интерфейс спроектировал с нуля: Compose и Clean Architecture, Supabase через REST, кэш на Room.

Kotlin, Jetpack Compose, Clean Architecture, BLE, Room, Supabase
